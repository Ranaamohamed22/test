# مساعد تقييم الإفادات

تطبيق Streamlit لتقييم الإفادات في ملفات Excel/CSV باستخدام OpenAI API، مع ملف موديل يحتوي على أمثلة صحيحة بتصنيف `0` أو `1`.

## طريقة الاستخدام محليًا

1. ثبّت Python 3.10 أو أحدث.
2. افتح Terminal داخل مجلد المشروع وشغّل:

   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```

3. أدخل مفتاح OpenAI API في الشريط الجانبي داخل التطبيق. لا تضع المفتاح في GitHub أو في الكود.
4. ارفع ملف الموديل الذي يحتوي على عمود الإفادات `Notes` وعمود التقييم (0/1).
5. ارفع الملف المراد تقييمه، ويجب أن يحتوي على عمود باسم `Notes` أو `الإفادة` أو `نص الإفادة`.
6. اضغط «ابدئي تقييم الإفادات»، ثم حمّل الملف الناتج.

## النشر على GitHub وStreamlit Community Cloud

1. أنشئ Repository جديدًا على GitHub، ويفضّل أن يكون **Private** إذا كان الكود مرتبطًا ببيانات العمل.
2. ارفع `app.py` و`requirements.txt` و`README.md` و`.gitignore` فقط. لا ترفع ملفات العملاء أو ملفات الموديل أو مفتاح API.
3. اربط المستودع بخدمة Streamlit Community Cloud وأنشئ التطبيق من ملف `app.py`.
4. افتح التطبيق وأدخل مفتاح API في خانته المخصصة. المفتاح لا يُحفظ داخل المستودع.

## قواعد التقييم المطبقة

- `1`: حدث تواصل فعلي، حتى لو رفض العميل السداد أو وعد به أو شرح حالته.
- `0`: نتيجة آخر متابعة كانت عدم رد/عدم إجابة/إغلاق الخط/بريد صوتي/المكالمة لا تتم وما شابه.
- آخر متابعة لها الأولوية: إذا وُجد وعد أو سداد سابق ثم انتهى النص إلى «الآن لا يرد» أو ما يعادلها، فالتقييم `0`.

## ملاحظات مهمة

- كل مرة تفتح فيها التطبيق، ارفع ملف الموديل وملف الإفادات المطلوب تقييمها.
- يستخدم التطبيق API خارجيًا؛ لا ترفع بيانات عمل حساسة إلا بعد التأكد من سياسة شركتك وموافقتها على المعالجة الخارجية.
- نتائج الذكاء الاصطناعي تحتاج مراجعة بشرية، خصوصًا الحالات الغامضة.
- ملف الناتج يحافظ على أعمدة الملف الأصلي، ويضيف/يحدّث عمود التقييم وعمود «سبب التقييم».
